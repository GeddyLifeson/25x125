# Mockups

Four screens with Humboldt Park sample data: `Main` (search, map and list), `Parcel`, `Feasibility` (scenarios A/B/C, sell/hold, incentive toggles, dollar margins), `Deals`.

These files were made in a design canvas and need its runtime (`support.js`) to render, so they won't open on their own in a browser. Read the HTML for layout, labels, copy and sample numbers. The live versions are at https://claude.ai/artifact/6DDPyW9FBpVud4X3ANfiU4.




## Revised 2026-10-29

Sample data and math now follow the revised spec: production-spec hard cost x the Humboldt Park adjustment, gross area capped by FAR, a contingency line, financing from the spec formula, 0.95 vacancy, margins that exclude land, a profit range, Opportunity Zone at $0 for build-and-sell, no utility placeholder, and no Redfin figures or Interim (production space, pop-up) items. The live canvas versions were not changed; republish them from these files if you want them to match.
