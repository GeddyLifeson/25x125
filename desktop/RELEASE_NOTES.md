25x125 as a Windows program for one person: no sign-in, no hosting, no payment. The database, engine and app run on your computer only.

Install: download `25x125-Setup-<version>.exe` below and double-click it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the program isn't code-signed). The first start loads the public data, which takes 1 to 2 hours and about 3 GB; keep the program open until the status window says it finished.

Full instructions: https://github.com/GeddyLifeson/25x125/blob/desktop-v0.1.0/desktop/README.md

Inside: PostgreSQL 16.13 with PostGIS 3.5.3, Python 3.12.10, the 25x125 engine, loaders and web app. Results are estimates, not tax, legal, zoning or appraisal advice.
