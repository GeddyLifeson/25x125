# This is the code editor, not the app

GitHub always opens this editor next to the app. You don't need it.

**The app opens in its own browser tab** when it is ready: about 1 minute on later starts, 15 to 20 minutes the first time (it builds the app and restores the data). The terminal at the bottom shows each step and then the app's address.

If no tab opened: click **Ports** at the bottom of this window, then the globe icon next to **25x125** (port 3000).

The app starts on the Search screen: pick an area, filter with the chips, click a parcel in the list or on the map, then run feasibility.

Keep this editor tab open while you use the app. The codespace stops after 30 minutes with the editor closed or idle.
