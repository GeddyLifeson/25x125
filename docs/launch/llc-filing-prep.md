# Illinois LLC filing prep (week 4)

Marlon files online with the Illinois Secretary of State (Articles of Organization, form LLC-5.5). Check the current fee on the site before filing.

| Field | Proposed |
| --- | --- |
| Name | [to confirm after the trademark check], LLC |
| Purpose | Developing and selling software and data services for real estate |
| Principal office | [Marlon's business address] |
| Registered agent | Marlon, or a registered agent service if the address should stay private |
| Organizer and manager | Marlon (member-managed) |
| Duration | Perpetual |

After filing:
1. Get an EIN from the IRS website (free, same day).
2. Open a business bank account.
3. Put the domain, hosting, Stripe, GitHub organization and trademark in the LLC's name.
4. Sign a short assignment moving the 25x125 code and docs from Marlon to the LLC.
